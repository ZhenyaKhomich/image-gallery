# 📷 Unsplash image-gallery

Приложение для поиска и отображения фотографий с использованием **Unsplash API**. Пользователь может вводить поисковый запрос, и приложение загрузит изображения соответствующей тематики.

---

## ✅ Описание проекта

**Unsplash** — один из крупнейших поставщиков бесплатных фотографий в интернете. Его API позволяет получать изображения по указанной тематике.

**Цель проекта** — создать приложение, которое:
- Загружает и отображает изображения с API при загрузке страницы.
- Позволяет искать фотографии по введенному запросу.
- Обеспечивает удобный и интуитивный интерфейс.

---

## 🔍 Функционал

✔️ При открытии приложения отображаются случайные фото с API.  
✔️ Есть строка поиска:
- Поиск осуществляется по нажатию **Enter** или кнопке отправки.
- После поиска фото обновляются, отображая результаты запроса.
- В поле поиска остаётся введённый запрос.

✔️ Кнопка очистки (**крестик**) — сбрасывает введённый запрос и возвращает **placeholder**.  
✔️ Поисковое поле:
- Курсор установлен по умолчанию при загрузке страницы.
- Есть **placeholder**.
- Отключено автозаполнение браузера.

✔️ Футер с:
- Ссылкой на **GitHub** автора.
- Годом создания приложения.
- Логотипом курса со ссылкой на него.
